# Meet Us in the Mountains

PROJECT: GOWDA × MALHOTRA
Wedding Website — Phase 1 Homepage Visual Prototype

You are an award-winning digital creative director, editorial web designer, UX designer, and frontend developer.

Build the first visual prototype of a sophisticated, cinematic, highly personalized wedding website for Sharanya Gowda and Sahil Malhotra.

IMPORTANT:
This is the FIRST ITERATION of a larger wedding website.

For this iteration, build a beautiful, responsive HOMEPAGE ONLY, with a reusable design system and navigation prepared for future pages.

Do not build the backend, database, RSVP system, authentication, guest management, or other pages yet.

Do not connect Supabase or any other backend service.

Do not create real forms that collect or store personal information.

Do not publish the website.

The goal is to establish the visual identity, emotional atmosphere, layout, typography, and interaction design.

--------------------------------------------------
1. CREATIVE VISION
--------------------------------------------------

The guiding principle is:

"Visually sophisticated. Behaviorally playful."

This should feel like a luxury editorial wedding website meets an atmospheric alpine travel experience.

Think:
- A beautifully art-directed magazine
- A luxury mountain resort
- A cinematic autumn travel film
- Contemporary editorial typography
- A subtle sense of humor
- A deeply personal love story

The wedding is elegant and formal, but the couple is playful, adventurous, and slightly unconventional.

Avoid:
- Generic wedding website templates
- Bohemian or rustic wedding aesthetics
- Excessive flowers
- Watercolor illustrations
- Cartoon mountains
- Clip art
- Overly decorative Indian wedding motifs
- Gold glitter
- Generic cursive wedding fonts
- Hearts everywhere
- Overly sentimental copy
- Excessive rounded cards
- A generic SaaS landing page aesthetic

This is not a corporate website.
This is not a wedding planning dashboard.

It should feel cinematic, romantic, editorial, and intentional.

3. VISUAL DESIGN SYSTEM
--------------------------------------------------

COLOR PALETTE

Primary background:
Warm ivory / soft cream

Primary text:
Deep charcoal

Primary dark accent:
Forest green

Secondary accents:
Burnt orange, autumn rust, deep burgundy

Subtle accents:
Muted gold and warm stone

Use the palette with restraint.

The website should not look orange everywhere.

Let photography carry much of the autumn color.

TYPOGRAPHY

Use an elegant, high-contrast editorial serif for major headlines.

Pair it with a clean, modern sans-serif for navigation, buttons, captions, and practical information.

Avoid overly ornamental script fonts.

Typography should feel sophisticated and contemporary.

Use generous whitespace, elegant spacing, and a clear hierarchy.

LAYOUT

Editorial rather than template-driven.

Use a combination of:
- Full-bleed photography
- Large expressive typography
- Thoughtful negative space
- Asymmetric compositions
- Refined image grids
- Subtle dividers
- Beautifully aligned content

Avoid making every section look like a row of identical cards.

4. HOMEPAGE HERO
--------------------------------------------------

Create a cinematic, atmospheric, full-screen hero.

The visual inspiration is the White Mountains in New Hampshire during peak autumn.

The ideal scene includes:
- Sweeping mountain ridgelines
- Rich fall foliage
- Atmospheric clouds
- Soft natural sunlight
- A sense of elevation
- Distant gondolas if they can be represented realistically

The result must feel photorealistic, not illustrated or cartoonish.

For this first prototype, use a high-quality visual treatment that can later be replaced with a custom 25–30 second cinematic video.

DO NOT attempt to generate the final wedding film.

Instead, create a beautiful hero capable of supporting a future background video.

Subtle atmospheric movement is welcome if it is lightweight and performant.

For example:
- Gentle image movement
- Soft gradient transitions
- Refined text reveals
- Minimal parallax

Avoid excessive animations.

--------------------------------------------------
7. INTERACTIONS
--------------------------------------------------

The website should feel alive but never distracting.

Use:
- Subtle scroll reveals
- Elegant hover states
- Smooth section transitions
- Thoughtful image interactions
- Restrained motion

Avoid:
- Excessive bouncing
- Constant moving elements
- Confetti
- Animated hearts
- Gimmicky cursor effects
- Auto-playing audio

Include reduced-motion support.

Do not add background music in this first iteration.

The final site may include optional licensed music later.

--------------------------------------------------
8. MOBILE EXPERIENCE
--------------------------------------------------

Design mobile-first.

Many guests will open this website from WhatsApp or SMS.

Ensure:
- Beautiful mobile hero composition
- Legible typography
- Clear primary actions
- Responsive editorial layouts
- Touch-friendly buttons
- Fast loading
- No horizontal scrolling
- Good image performance

The mobile experience should feel intentionally designed, not like a compressed desktop page.

--------------------------------------------------
9. TECHNICAL BOUNDARIES
--------------------------------------------------

This is a FRONTEND VISUAL PROTOTYPE ONLY.

Do not:
- Create a database
- Implement authentication
- Create RSVP storage
- Add payment functionality
- Integrate external wedding platforms
- Create an administrative dashboard
- Request personal guest information
- Build a registry
- Build guest photo uploads
- Publish the website

Use reusable components and a maintainable structure.

Use semantic HTML and accessible interactions.

Keep placeholder content clearly identifiable.

Do not invent personal details, private events, or wedding logistics.

--------------------------------------------------
10. QUALITY BAR
--------------------------------------------------

The finished homepage should look like it was designed by a high-end creative studio.

It must not look like a generic AI-generated landing page.

Prioritize:
1. Visual sophistication
2. Emotional atmosphere
3. Authenticity
4. Excellent typography
5. Mobile usability
6. Clear navigation
7. Performance

Make thoughtful design decisions.
